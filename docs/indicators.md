# Indicator library (`money.hejje.market.indicators`)

Deterministic, incremental indicators shared by the backtester and the live signal engine (README rule 10). An
`IndicatorContext` exists per (instrument, timeframe); it is fed one **closed** candle at a time
(`onCandleClosed`, or `warmUp(List<Candle>)` from history) and implements the DSL's `BarContext`, so a condition is
always evaluated against the bar that just closed. Values are readable only for closed bars: look-ahead is impossible
by construction. An indicator that has not seen enough bars is *not ready* (empty value) and any condition referencing
it evaluates to `NOT_READY`, which never counts as true.

Every indicator keeps a per-bar history, so `ema(20)[3]` and `close[1]` are the values three and one closed bars back.

## Conventions (TA-Lib)

The golden fixture `server/src/test/resources/indicators/golden.csv` is generated by
`research/tools/gen_indicator_fixtures.py` with TA-Lib (classic indicators) and pandas (session-based ones); the Java
implementations match it within 1e-6 on every bar and are not ready exactly where the reference has no value.

| Indicator | First value | Rule |
|---|---|---|
| `sma(n)` | bar n | mean of the last n closes |
| `ema(n)` | bar n | seeded with the SMA of the first n closes, then `alpha = 2/(n+1)` |
| `rsi(n)` | bar n+1 | Wilder: first average gain/loss = mean of the first n changes, then `(avg·(n−1) + x)/n`; 0 when both averages are 0 |
| `atr(n)` | bar n+1 | true range needs a previous close; first ATR = mean of the first n true ranges, then Wilder smoothing |
| `adx(n)` | bar 2n | +DM/−DM/TR sums seeded over the first n−1 changes, Wilder-smoothed from the n-th change; DX from bar n+1; ADX = mean of the first n DX values, then Wilder smoothing |
| `bb_upper(n, k)`, `bb_lower(n, k)` | bar n | SMA(n) ± k × population standard deviation |
| `highest(n)`, `lowest(n)` | bar n | highest high / lowest low of the last n bars including the current one |
| `vwap` | first bar of the session with volume | Σ typical price × volume / Σ volume since 09:15; resets each session; **not ready on index series (no volume)** — use the future |
| `opening_range_high(15m)`, `opening_range_low(15m)` | the bar closing at 09:15 + range | high/low of bars opening before 09:15 + range; constant for the rest of the session; the range must be a whole number of bars |
| `relative_volume(n)` | second session with the slot | bar volume ÷ mean volume of the same time-of-day slot over the previous n sessions (fewer while history is short; the current bar never counts toward its own baseline) |
| `prev_day_high`, `prev_day_low`, `prev_day_close` | second session | previous session's extremes/close, tracked from the intraday bars fed to the context (`SessionTracker.seedPreviousDay` seeds them from a daily candle when warm-up starts mid-way) |
| `gap_pct` | first bar of the second session | (session open − previous close) / previous close × 100 |
| `session_minutes` | bar 1 | whole minutes from 09:15 to the bar's close |

Sessions are IST dates of the candle open time. Warm-up needs one full previous session for the previous-day, gap and
relative-volume indicators, and `2n` bars for `adx(n)`; the backtester and signal engine warm up from history before
the first live bar.

Indicator arithmetic uses `double` (analytics, not money). Stop and target levels derived from indicator values are
converted to tick-aligned `Price`s when an order is prepared.
