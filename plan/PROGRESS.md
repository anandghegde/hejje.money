| M4.1 | 2026-09-10 | (this commit) | `llm` module completed. Provider-neutral conversations and tools: `LlmMessage` (user / assistant with tool calls / tool result), `LlmTool` (name, description, JSON schema), `LlmToolCall`; `LlmRequest` gains `messages` + `tools` (old constructor kept, `chat(...)` factory, `promptText()` hashed for the log), `LlmResponse` gains `toolCalls` + `finishReason`, `LlmChunk` carries the full response on the last chunk, `LlmStreams.cold` (a publisher that starts producing only once subscribed; the M3.4 default could drop chunks). `OpenAiCompatibleProvider` rewritten: messages/`tools`/`tool_calls`/`role: tool`, arguments parsed from the JSON string, native SSE streaming with `stream_options.include_usage` and tool-call fragments assembled by index.
